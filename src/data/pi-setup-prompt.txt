=== STEP 4 — default model ===
Merge into SETTINGS (create the file and its parent directories if absent;
preserve every existing key):
    defaultProvider      = "zai"
    defaultModel         = "glm-5.3"
    defaultThinkingLevel = "max"
Use a JSON-aware merge, never a text substitution. A portable way that works
on every platform, because Node is guaranteed present after STEP 1:

    node -e "const fs=require('fs'),os=require('os'),p=require('path');const f=p.join(os.homedir(),'.pi','agent','settings.json');fs.mkdirSync(p.dirname(f),{recursive:true});const c=fs.existsSync(f)?JSON.parse(fs.readFileSync(f,'utf8')):{};c.defaultProvider='zai';c.defaultModel='glm-5.3';c.defaultThinkingLevel='max';fs.writeFileSync(f,JSON.stringify(c,null,2));console.log('wrote',f)"

`os.homedir()` resolves correctly on all three platforms, which is why this is
preferred over hardcoding `~` or `%USERPROFILE%`. Mind the quoting: on
PowerShell wrap the script in single quotes and use double quotes inside, or
write the script to a temporary .js file and run that.
